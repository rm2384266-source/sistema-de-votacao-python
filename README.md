# Sistema de Votação em Python
Esse é um projeto simples que fiz durante meus estudos de Python.

## Sobre o projeto
O programa simula um sistema de votação.
Ele permite registrar os votos e verificar os resultados da votação.

## O que utilizei
- Python
- Variáveis
- Listas
- Estruturas de repetição
- Condições `if`
- Entrada de dados com `input()`
- Saída de dados com `print()`
## Objetivo
Esse projeto foi feito para praticar meus conhecimentos iniciais de programação e Python.
