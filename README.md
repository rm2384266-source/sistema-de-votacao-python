# Sistema de Votação em Python

Projeto acadêmico desenvolvido em grupo durante meus estudos de Python.

## Sobre o projeto

O programa simula um sistema simples de votação.

Ele permite registrar os votos e apresentar os resultados da votação. O projeto foi desenvolvido com o objetivo de praticar conceitos básicos de programação utilizando Python.

## O que utilizei

- Python
- Variáveis
- Listas
- Estruturas de repetição (`for`)
- Estruturas condicionais (`if`)
- Entrada de dados com `input()`
- Saída de dados com `print()`

## Objetivo

Este projeto foi desenvolvido como uma atividade de aprendizado, com o objetivo de praticar meus conhecimentos iniciais de programação e Python.

Por ser um projeto desenvolvido em grupo, algumas partes foram realizadas em colaboração com outros integrantes.

## Participação

Participei do desenvolvimento do projeto, contribuindo para a implementação e compreensão das funcionalidades do sistema e dos conceitos utilizados em Python.
